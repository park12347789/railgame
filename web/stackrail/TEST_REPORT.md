# StackRail v0.1 검증 기록

검증일: 2026-09-15. 결과는 로컬 실행 기준이며 GitHub Actions 실행 결과가 아닙니다.

## 운영 로직

명령: `node --test tests/sim.test.cjs`

결과: **22 tests / 22 pass / 0 fail**.

범위: 직원·시설 유지, 카드 호환성, 잘못된 입력, 작업 시간, 중복 회수 방지, 대기열 상한, 창고 상한, 열차 상태 전이, 승강장 배타성, 자동 상차, 출발 중복 지급 방지, 정비 조건, 매점, 확장 비용·상한, 저장 복원·손상 저장 거부, 승리·실패·자유 운영.

자원을 추가하거나 자금을 편집하지 않는 자동 운영 정책:

```json
{"time":245.34999999999658,"cash":825,"full":9,"rep":100,"end":"win"}
```

해당 정책은 두 번째 승강장과 작업 속도 개선을 구매하고, 고장 열차가 오면 매점 직원을 정비소로 이동합니다. 단위 테스트 중 경계조건 테스트는 별도의 합성 상태를 사용합니다.

## 브라우저 조작

명령: `node build.cjs` 이후 `python tests/browser_smoke.py`.

결과: 데스크톱 1440px / 터치 에뮬레이션 390×844 모두 통과, JavaScript 예외 0건.

- 직원과 목재 카드 실제 마우스 드래그, 다른 직원·물자의 클릭 배치.
- 작업 완료, 자동 적재, 만차 출발 수익 99 G, 중복 없는 지급.
- 승강장 구매 후 여객·화물열차 두 편 동시 정차.
- 실제 마우스로 시점 회전, 카메라 초기화, Space 일시정지.
- 모바일 크기에서 직원·물자 탭 배치, 출발, 페이지 가로 넘침 없음.
- 3D 메시 삼각형 수 1,000개 초과 확인.

자동화는 경과 시간에 대해 진단 API로 시뮬레이션을 전진시킵니다. 위 조작 검사는 DOM 마우스/키보드/터치 입력으로 수행합니다. 긴 실시간 수동 플레이 세션을 대신하지 않습니다.

## 검증하지 않은 항목

1. **GPU WebGL 경로:** 테스트 환경에서 WebGL을 제공하지 않아 같은 메시의 소프트웨어 3D 투영 경로를 검사했습니다. GPU 경로는 추가 기기 확인이 필요합니다. 소프트웨어 경로에는 painter 정렬 특유의 가림 오차가 생길 수 있습니다.
2. **실제 origin 저장:** 브라우저 URL 이동 제한으로 인라인 HTML을 `set_content`에 전달했습니다. 이 opaque origin에서는 저장 불가 처리만 확인했으며, 저장 데이터의 직렬화/복원 자체는 Node 테스트로 확인했습니다.
3. **Android/iOS 실기기:** 390px 터치 에뮬레이션 결과이지 실기기 성능·호환성 보장이 아닙니다.
4. **공개 배포:** GitHub Pages나 외부 정적 호스팅에는 배포하지 않았습니다.

브라우저 정책이나 사용자 시스템 설정은 변경하지 않았습니다. 게임 실행에 외부 네트워크 호출이나 서드파티 에셋은 필요하지 않습니다.
